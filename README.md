# Classificador de Heróis 🧙‍♂️

Projeto simples desenvolvido para praticar lógica de programação e manipulação do DOM com JavaScript.

O usuário digita o nome do herói e sua quantidade de XP, e o sistema retorna a classificação do herói de acordo com a tabela de níveis.

---

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

---

## Como funciona

1. O usuário digita o nickname do herói
2. Informa a quantidade de XP
3. O sistema calcula o nível automaticamente
4. O resultado é exibido na tela

Classificações:

| XP | Nível |
|----|------|
< 1000 | Ferro |
1000 - 1999 | Bronze |
2000 - 4999 | Prata |
5000 - 6999 | Ouro |
7000 - 7999 | Platina |
8000 - 8999 | Ascendente |
9000 - 9999 | Imortal |
>= 10000 | Radiante |

---

## Objetivo do projeto

Praticar:

- lógica condicional
- captura de dados do formulário
- manipulação do DOM
- eventos em JavaScript
